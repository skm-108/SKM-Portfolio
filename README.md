# SKM Portfolio

Portfolio website for Shivam Kumar Mishra, an AI engineer and full-stack developer focused on RAG systems, AI agents, cybersecurity workflows, intelligent automation, and production-ready software.

## Highlights

- Recruiter-focused hero section
- AI and full-stack project showcase
- Case studies for Clip Mind and DocuSPARK
- Technical skills grid with technology logos
- Blog section for featured LinkedIn posts, Medium articles, and native technical writing
- Downloadable resume and portfolio PDF
- SEO, Open Graph, and LinkedIn preview metadata
- Vercel Analytics integration

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Vercel Analytics
- jsPDF and html2canvas for portfolio PDF export

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
